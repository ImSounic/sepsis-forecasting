# Outputs Directory Structure

## models/
Trained model checkpoints and saved models.
- gru/: GRU model checkpoints
- lightgbm/: LightGBM baseline and improved models
- ensemble/: Ensemble predictions

## figures/
All generated visualizations.
- gru/attention/: Attention weight distributions
- gru/patients/: Patient-level attention visualizations (TP/FP/TN/FN)
- shap/: SHAP feature importance plots
- lightgbm/: LightGBM feature importance
- ensemble/: Model agreement analysis
- training/: Training curves

## docs/
Project documentation and reports.
