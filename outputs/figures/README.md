# Explainability Figures

Generated by `python -m src.explainability.run_analysis --config configs/optimized.yaml`

## Folder Structure

### attention/
Aggregate attention weight analysis across the full validation set.

- `attention_distribution.png` - Mean attention weights by prediction outcome (TP/FP/TN/FN) with standard deviation bands
- `mean_attention_by_hour.png` - Average attention weight per hour across all samples, showing which hours the model focuses on

### patients/
Individual patient attention plots (5 per category = 20 total + 1 highest prediction).

- `patient_attention_tp_*.png` - True Positive examples (correct sepsis detection)
- `patient_attention_fp_*.png` - False Positive examples (false alarms)
- `patient_attention_tn_*.png` - True Negative examples (correct non-sepsis)
- `patient_attention_fn_*.png` - False Negative examples (missed sepsis)
- `patient_attention_highest_pred_*.png` - Sample with highest prediction probability

Each plot overlays attention weights on vital sign trajectories within the 24-hour input window.

### shap/
SHAP (SHapley Additive exPlanations) feature importance analysis.

- `shap_feature_importance.png` - Top 20 features ranked by mean |SHAP value| across all timesteps
- `shap_temporal_importance.png` - Importance by hour position, showing which timesteps matter most

### comparison/
Model comparison between GRU+Attention and LightGBM baseline.

- `feature_importance_comparison.png` - Side-by-side normalized feature importance (GRU SHAP vs LightGBM gain)
